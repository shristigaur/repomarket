NEXT STEPS (10 MINUTES)
================================================================================

STEP 1: Get Resend API Key (2 minutes)
────────────────────────────────────────
1. Go to https://resend.com
2. Sign up (free account)
3. Go to https://resend.com/api-keys
4. Create API key
5. Copy key (starts with "re_")

STEP 2: Update Local .env (1 minute)
────────────────────────────────────────
Edit backend/.env:

REMOVE:
  EMAIL_USER=...
  EMAIL_PASS=...

ADD:
  RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx

STEP 3: Test Locally (3 minutes)
────────────────────────────────────────
cd backend
npm install resend
npm start

Then test OTP:
1. Signup with test email
2. Request OTP
3. Check email inbox
4. Verify OTP works

STEP 4: Deploy (4 minutes)
────────────────────────────────────────
git add -A
git commit -m "refactor: replace Nodemailer with Resend API"
git push origin main

Then in Render Dashboard:
1. Remove: EMAIL_USER, EMAIL_PASS
2. Add: RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
3. Save
4. Wait for auto-deploy (2-5 minutes)

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "RESEND_API_KEY is not configured"
Solution: Add RESEND_API_KEY to backend/.env and restart

Problem: "Failed to send verification email"
Solution: Check API key is valid, restart backend

Problem: "Cannot find module 'resend'"
Solution: Run "npm install resend" in backend directory

Problem: Deployment fails
Solution: Check git push succeeded, verify package.json is correct
